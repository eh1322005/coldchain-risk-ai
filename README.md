# 🐟 ColdChain Risk AI
### Seafood Spoilage Prediction System

## 📌 Problem Statement

Seafood products are highly perishable and spoil rapidly when cold-chain conditions are not maintained. The goal of this project is to **predict the spoilage risk score (0–100)** for a shipment based on environmental, logistics, and operational conditions — allowing managers to intervene before spoilage occurs.

## 🚀 Quick Start

### 1. Clone the repo
```bash
git clone https://github.com/YOUR_USERNAME/seafood-spoilage-predictor.git
cd seafood-spoilage-predictor
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Add your dataset
Place the CSV file inside the `data/` folder:
```
data/tm271_cold_chain_spoilage_risk_dataset.csv
```

### 4. Train the model
```bash
python train.py
```

### 5. Launch the app
```bash
streamlit run app.py
```

## 📊 Dataset

| Property | Value |
|----------|-------|
| Records | 480 shipments |
| Features | 13 raw + 3 engineered |
| Target | `Spoilage_Risk_Score` (0–100) |
| Task | Regression |

### Feature Categories

**🌡️ Environmental**
- `Avg_Storage_Temp_C` — Internal refrigerator temperature
- `Ambient_Temp_C` — External environment temperature
- `Relative_Humidity_Pct` — Humidity during transport
- `Temp_Excursion_Hours` — Hours with unsafe temperature

**🚛 Logistics**
- `Transit_Duration_Hours` — Total journey time
- `Distance_KM` — Shipment distance
- `Fuel_Use_Liters` — Fuel consumed
- `Vehicle_Load_Pct` — Vehicle capacity used

**⚙️ Operational**
- `Packaging_Quality_Score` — Packaging effectiveness (0–10)
- `Door_Open_Events` — Number of refrigerator door openings
- `Ice_Replacement_Count` — Ice pack replacements during journey
- `Inspection_Hygiene_Score` — Hygiene compliance score (0–10)

---

## 🔬 Feature Engineering

| Feature | Formula | Insight |
|---------|---------|---------|
| `Temp_Abuse_Index` | `Temp × Excursion_Hours` | Cumulative thermal damage |
| `Cooling_Protection_Ratio` | `(Packaging + Ice) / Duration` | Protection vs exposure time |
| `Load_Stress_Index` | `(Load% × Duration) / 100` | Physical stress on cargo |
| `Thermal_Exposure_Index` | `(StorageTemp + AmbientTemp) × ExcursionHours` | Combined thermal stress |
| `Logistics_Inefficiency_Index` | `Fuel / Distance` | Route efficiency |

## 🤖 Models Evaluated

| Model | MAE | RMSE | R² |
|-------|-----|------|-----|
| **Linear Regression** ✅ | **4.33** | **6.11** | **0.864** |
| Random Forest | 5.60 | 8.53 | 0.736 |
| Gradient Boosting | 5.60 | 8.53 | 0.736 |
| Decision Tree | 7.71 | 10.41 | 0.607 |
| SVR | 8.80 | 14.81 | 0.204 |

**Linear Regression** outperformed ensemble models because feature engineering transformed complex relationships into a highly linear representation.
